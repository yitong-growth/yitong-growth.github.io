# 益童成长智能体

保留课程内容的静态网页与 PWA，可在电脑、安卓及苹果浏览器中使用。

GitHub 只用于托管网页，访问课程无需 ChatGPT 或 GitHub 账号。账号、成绩、作品与笔记保存在当前设备的浏览器中。本版本不提供跨设备自动同步。

`site.zip` 为网页运行文件；`.github/workflows/pages.yml` 自动发布到 GitHub Pages。在仓库的 Settings → Pages 中把 Source 设为 GitHub Actions，默认分支使用 `main`。

更换课程网址前，从旧网页导出“完整备份”；在新网页注册相同学号，进入相同数据区恢复。不要先清除旧网页的浏览器记录。

如需本地离线使用，将 `site.zip` 解压到完整文件夹后打开 `index.html`。在线版可按浏览器安装指引添加到主屏幕。GitHub Pages 在国内能否顺畅访问取决于学校和移动网络，须实际测试；电脑离线文件版不依赖外网。

内置历史档案及十张设计图均为课程示例，实际成绩和作品由使用者录入。没有包含真实用户记录、模型密钥或服务器账号。
